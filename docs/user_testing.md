# Real-User Test Record

The capstone requires testing with **three real users**. Do not fabricate these results. Ask three people to use the deployed application and record their feedback here.

## Test protocol

Give each tester the live URL and login credentials. Ask each person to:

1. sign in;
2. ask at least three football-law questions;
3. open at least one retrieved source;
4. rate answer clarity and trustworthiness;
5. report any confusing behavior or incorrect answer.
